# 证据质量与偏倚风险

## 适用场景

评价单项研究或一组研究能否支持某个结论；为综述、审稿、指南、投稿前审查写“证据强度/局限性”；判断一个显著结果是真效应、偏倚还是偶然。

## 一、先问“这个设计能回答什么”

| 设计 | 能较强回答 | 主要弱点 |
| --- | --- | --- |
| 随机对照试验（RCT） | 干预的因果效应 | 外部有效性、依从性、盲法、样本量 |
| 析因/交叉/整群 RCT | 交互、个体内比较、群组干预 | 顺序效应、整群方差、实施复杂 |
| 前瞻性队列 | 暴露与结局的时间顺序、发病率 | 混杂、失访、暴露测量 |
| 病例对照 | 罕见结局、病因假设 | 选择偏倚、回忆偏倚、时间性 |
| 横断面 | 流行率、相关性 | 不能定因果、时序不清 |
| 自身对照/前后比较 | 干预前后变化 | 回归到均值、时间趋势、伴随干预 |
| 体外/动物 | 机制、剂量反应 | 外推限制、物种差异 |
| 诊断准确性 | 敏感度/特异度 | 谱偏倚、参考标准、验证偏倚 |
| 预测模型 | 风险分层 | 过拟合、校准、外部验证 |
| 系统综述/meta | 综合证据 | 检索偏倚、异质性、发表偏倚 |

设计等级不是绝对排序：一个设计良好的队列可以比一个高偏倚风险的 RCT 更有说服力；关键是偏倚控制与问题匹配。

## 二、内部有效性：六类偏倚

1. **选择偏倚**：纳入/排除、志愿者、转诊、幸存者、健康工人效应。
2. **信息/测量偏倚**：回忆、社会期望、测量误差、盲法缺失、分类错误。
3. **混杂**：第三变量同时影响暴露与结局；可测量/未测量；方向可正可负。
4. **实施偏倚**：依从性、共同干预、实施差异、污染。
5. **损耗偏倚**：失访、退出、死亡；与暴露/结局相关时不随机。
6. **报告偏倚**：选择性报告结局、亚组、时间点；发表偏倚。

对每个偏倚问：它是否与暴露/干预和结局都相关？方向是什么？能否调整/分层/敏感性分析？

## 三、常用风险偏倚工具

只在适用时使用；不要为了显得专业而套错工具。

- **RoB 2**：随机试验，五个域（随机化、偏离干预、缺失数据、结局测量、结果选择）。
- **ROBINS-I**：非随机干预研究，七个域（混杂、选择、分类、偏离、缺失、测量、报告）。
- **QUADAS-2**：诊断准确性，患者选择、指数试验、参考标准、流程/时序。
- **PROBAST**：预测模型，参与者、预测因子、结局、分析。
- **AMSTAR 2**：系统综述的方法学质量。
- **JBI 清单**：质性研究、描述性研究、病例系列等。
- **Newcastle-Ottawa Scale**：观察性研究（常用但粗糙，需说明局限）。

工具给出的是结构化的偏倚判断，不是“质量分数”。不要用总分掩盖关键域的问题。

## 四、外部有效性

- 人群：年龄、性别、共病、遗传背景、纳入标准。
- 干预：剂量、疗程、实施方式、依从性。
- 对照：常规护理 vs 安慰剂 vs 无干预。
- 结局：替代终点 vs 硬终点；短期 vs 长期。
- 场景：医院/社区、资源水平、诊断路径。
- 时间：随时间变化的治疗背景。

外部有效性不是“越像我的样本越好”，而是明确结果能外推到哪个人群/条件。

## 五、效应度量与不确定性

- **二分类**：风险比（RR）、风险差（RD）、优势比（OR）；OR 在常见结局时高估 RR。
- **连续**：均值差（MD）、标准化均值差（SMD）；SMD 的临床意义需谨慎。
- **时间事件**：HR、中位生存、限制平均生存时间；检查比例风险假设。
- **计数**：率比、发生率差。
- **诊断**：敏感度、特异度、似然比、预测值（依赖患病率）。
- **模型**：区分度（AUC）、校准、净获益；AUC 高不代表临床有用。

报告效应量 + 95% CI + 精确 p 值；不要只报“显著/不显著”。不显著时看 CI 是否排除了有临床意义的效应。

## 六、证据确定性

写“高/中/低/极低确定性 + 理由”是可以的；不要冒充完整 GRADE 评级。判断维度：

- **偏倚风险**：关键域是否严重。
- **不一致性**：研究间方向/大小是否一致；能否解释。
- **间接性**：人群/干预/结局/对照是否直接。
- **不精确性**：样本量/事件数/CI 宽度。
- **发表偏倚**：小样本阳性研究集中、漏斗图不对称、注册结局缺失。
- **效应量**：大效应、剂量反应可提升确定性；但大效应也可能来自偏倚。

升级/降级都要写理由，不要只给等级。

## 七、常见误用

- 把“随机”当成“无偏”；随机化失败、盲法缺失、依从性差仍会偏。
- 把“统计显著”当成“证据强”；小样本显著效应常不稳定。
- 把“不显著”当成“无效应”；CI 可能包含重要效应。
- 用亚组/事后分析支撑主要结论；多重比较未校正。
- 把体外/动物结果直接外推到临床。
- 用替代终点代替硬终点，却不说明。
- 把观察性研究的调整后关联写成因果。
- 用“ GRADE 1A”但没有做系统评价；等级是过程产物，不是标签。
- 忽视失访/缺失数据；完整病例分析可能引入偏倚。

## 八、实践建议

1. 先写问题类型，再选设计与工具。
2. 对每项研究画“暴露/干预 → 结局”的因果图，标出混杂与选择路径。
3. 关键偏倚逐个判断方向与大小；不要只给总分。
4. 提取效应量、CI、n、事件数；不要只抄 p。
5. 检查预设结局/分析是否与报告一致（注册库/方案）。
6. 对缺失数据做敏感性分析；说明假设。
7. 综合时按一致性、直接性、精确性、偏倚、发表偏倚写确定性。
8. 结论措辞与证据强度匹配：强证据用“支持”，弱证据用“提示/与…一致”。
9. 对不确定的地方保留不确定性，不要为了叙事完整而补全。
10. 审稿/复核时，把“证据缺口”写成可验证的补充分析或数据，而不是“需要更多研究”。
