# Hypothesis Testing and P Values

## 适用场景

比较组间差异、判断关联是否可能由随机波动造成，以及评估结论的统计稳健性。

## 核心概念

- **零假设与备择假设**：H0 与 HA 必须在看数据之前确定。事后根据结果挑选假设会让 P 值失去意义。
- **P 值的定义**：在 H0 为真且模型假定的前提下，观察到当前结果或更极端结果的概率。它不是「H0 为真的概率」。
- **显著性水平 α**：事先约定的判定阈值，常见 0.05。P 值小于 α 时称「统计显著」，但不代表效应大或结论重要。
- **两类错误**：I 类错误（H0 为真却拒绝，概率约等于 α）与 II 类错误（真实效应却未发现，概率 β）。统计功效 = 1 − β，常用目标 0.8。
- **效应量与置信区间**：报告均值差、风险比、标准化效应量（Cohen's d 等）及其 95% 置信区间，比单纯报告 P 值更能说明实际意义。

## 常见误用

- 把 P = 0.049 与 P = 0.051 当成「有/无」的质变；它们本质上是连续量。
- 用「P 值更小」比较两个检验的效应强弱，或比较不同研究之间的显著性。
- 把「不显著」解释为「没有差异」；样本量不足时尤其危险。
- 多次检验、多个终点或中途查看数据后不校正。
- 只在结果显著时才报告，或根据结果反复挑选检验方法。

## 实践建议

1. 先写分析计划：主要终点、检验方法、校正策略、样本量。
2. 报告效应量、置信区间与精确 P 值，而不只是一个星号。
3. 检查检验假设（独立性、分布、方差齐性）；不满足时考虑稳健或非参数方法。
4. 预先说明缺失值、异常值与排除标准。
