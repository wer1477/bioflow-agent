# 假设构建与可检验性

## 适用场景

从文献空白、初步观察或异常结果提出假设；比较多个竞争解释；判断一个假设是否可检验、是否新颖、是否值得做；为实验设计提供判别性预测。

## 一、假设不是预测，也不是结论

- **假设**：对世界如何运作的一个可检验陈述，通常包含机制或因果方向。
- **预测**：如果假设为真，在某个具体条件下应该观察到什么。
- **结论**：数据支持/不支持假设后的判断。

一个假设可以有很多预测；一个预测失败不一定杀死假设（可能有附加条件），但一组关键预测失败会。

## 二、好假设的五个特征

1. **具体**：对象、条件、方向、结局明确；不是“X 参与 Y 调控”这种万能句。
2. **可检验**：能通过观察/实验产生支持或反对的证据。
3. **可证伪**：预先说明什么结果会让假设降权/放弃。
4. **有机制**：不只是相关性，能说出一个可操作的因果路径。
5. **有区分力**：与竞争解释做出不同预测，而不只是“也会导致类似结果”。

补充：

- **一致性**：与已知证据不冲突；冲突处有解释。
- **范围**：适用于哪些物种/人群/条件；不要无限外推。
- **可操作性**：需要的数据/实验是否可及。
- **新颖性**：相对先行工作增量在哪。

## 三、从观察到假设

1. **固定观察**：写清数据、单位、条件、重复、混杂；区分事实与推断。
2. **列竞争解释**：至少 3 个，包括技术/统计解释（批次、选择、测量、回归到均值、多重比较）。
3. **写机制**：每个解释一句话因果路径；画简单因果图（暴露/干预 → 中介 → 结局，混杂指向两边）。
4. **推导预测**：在新数据/新条件下，每个解释的预测有何不同。
5. **设计判别**：什么观察/实验能区分；需要什么精度/样本。
6. **写证伪条件**：什么结果会杀死/降权假设。
7. **评估新颖性与可行性**。
8. **排序并推荐 1–2 个先做**。

## 四、竞争解释的常见来源

- **生物学**：表达、剪接、蛋白稳定性、定位、相互作用、代谢、细胞状态、发育阶段。
- **技术**：批次、归一化、抗体特异性、测序深度、分割/标注误差、阈值。
- **统计**：样本量不足、选择偏倚、混杂、回归到均值、多重比较、过拟合、数据泄漏。
- **因果方向**：A→B、B→A、共同原因、选择效应、反向因果。
- **系统差异**：物种、细胞系、剂量、时间窗、组织、遗传背景、环境。
- **发表/报告**：只报阳性、只报显著亚组、结论被标题放大。

把技术/统计解释写进竞争假设不是“自我否定”，而是让生物学结论更可信。

## 五、判别性预测

好预测：

- 方向明确（升高/降低/无变化）。
- 条件明确（哪个系统、剂量、时间点）。
- 可观测（现有或可获得的技术）。
- 与至少一个竞争假设的预测不同。
- 失败时有解释空间（不是“必然证伪”）。

差预测：

- “会有变化”“可能相关”“需要进一步研究”。
- 只能被同一套数据支持，无法被新数据检验。
- 事后根据结果调整预测（HARKing）。

## 六、HARKing 与事后假设

HARKing（Hypothesizing After Results are Known）是把事后发现包装成事前假设。它会：

- 高估证据强度；
- 使 p 值/置信区间失去校准意义；
- 让后续研究重复失败。

避免方法：

- 在分析前写预测、分析计划、主要终点；保存版本/时间戳。
- 探索性分析明确标 exploratory，不冒充确证性。
- 如果事后提出新假设，写成“探索性发现，需独立验证”，不要改写历史。
- 预注册/注册报告适用于确证性研究；小规模探索也要保留分析日志。

## 七、新颖性与增量

新颖性不等于“没人做过”：

- **新问题**：之前没被明确提出。
- **新机制**：已知关联，但因果路径不同。
- **新数据**：新人群/物种/条件/尺度，能改变结论。
- **新方法**：能解决旧方法的关键限制。
- **新应用**：把已知机制用于新场景，且有实际价值。

判断时要回答：

- 最接近的 3–5 篇工作是什么？
- 它们没回答什么？为什么没回答？
- 你的增量是否足以改变领域判断/实践？
- 如果结果是负的，是否仍有信息量？

不要用“据我所知没人做过”代替检索。

## 八、可行性与伦理

- 数据是否已有/可获取？样本是否稀有？
- 实验平台、时间、成本、技术风险。
- 伦理审批、动物福利、患者隐私、数据许可。
- 负结果是否可发表/可解释。
- 如果只能做观察性研究，因果主张要降级。

## 九、排序与决策

排序标准要显式：

| 标准 | 问题 |
| --- | --- |
| 证据支持 | 现有证据多强？ |
| 判别力 | 能否区分竞争假设？ |
| 新颖性 | 增量在哪？ |
| 可行性 | 时间/成本/风险？ |
| 影响 | 如果为真，改变什么？ |
| 风险 | 失败是否可接受？ |

可以给权重/分数，但必须写理由。推荐“先做”的假设要附判别实验和最小可行数据。

## 十、常见误用

- 把相关性当机制；把“相关”写成“调控/导致”。
- 假设太宽，任何结果都能支持。
- 没有竞争假设，只有一个主假设和两个稻草人。
- 预测与假设同义反复。
- 事后改假设/改终点。
- 用“更多数据/更多实验”当假设。
- 只追求新颖，忽略可行性和伦理。
- 把预印本/会议摘要当已确立证据。
- 假设太多，没有判别路径。

## 十一、实践建议

1. 先写观察，再写解释；观察不稳定时先验证观察。
2. 至少 3 个竞争解释，包含技术/统计解释。
3. 每个假设写：机制、预测、证伪条件、所需数据。
4. 做一次 bounded 文献检索，确认新颖性和先行工作。
5. 用判别矩阵比较，不只比较“合理性”。
6. 把探索性发现与确证性假设分开。
7. 交付时给排序理由和最小可行验证方案。
8. 对不确定的机制保留多种可能，不要过早收敛。
