# Research Methods and Communication

Method-level capabilities for framing hypotheses, designing studies, appraising evidence, writing manuscripts, and reviewing research.

## Skills

- bio-report（skill：bio-report）：Assemble a reproducible report from analysis manifests, result tables, figures, and a methods section: Markdown plus an optional matplotlib PDF, with tool versions and input/output sha256.

- evidence-appraisal（skill：evidence-appraisal）：Build a claim-evidence matrix linking each claim to a verbatim source, locator, support/contradict verdict, confidence, and retraction status. Use to verify references, audit a manuscript's evidence chain, or grade evidence.
- experiment-design（skill：experiment-design）：Turn a hypothesis into an executable design: estimand, controls, randomization, blocking, sample size/power, multiplicity, missing-data plan, statistical analysis plan, and reproducibility contract. Use before running an experiment or analysis.
- hypothesis-design（skill：hypothesis-design）：Generate and stress-test hypotheses: rival explanations, discriminating predictions, falsification conditions, novelty/feasibility checks, and a ranked shortlist. Use after observations or a literature gap, before designing the final study.
- peer-review（skill：peer-review）：Review a manuscript or deliverable in explicit modes: mechanical checks, claim-evidence audit, methods/statistics/reproducibility review, novelty check, and severity-ranked findings. Use for pre-submission review, a reviewer report, or a rebuttal check.
- scientific-writing（skill：scientific-writing）：Assemble a submittable manuscript from results and evidence: claim-evidence matrix, section contracts, figures/tables, reporting-checklist mapping, reference verification, cover letter, and response to reviewers. Use for drafting, revision, and submission.
