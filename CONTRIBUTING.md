# Contributing

Thanks for your interest in Bioflow.

1. Open an issue describing the bug or feature before large changes.
2. Keep pull requests focused; include tests where possible.
3. Do not commit credentials, private data, or workspace artifacts.
4. Run `npm run build` and `npm run test` in `agent-client/` before opening a PR.
5. By contributing, you agree that your contributions are licensed under Apache-2.0.
